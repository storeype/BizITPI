# Modal Shift Analytics - Perfetti Van Melle

Website for the KEDGE MSc ITML Business Intelligence project (Section 1, Group 2, Brief 8): road, rail or barge for PVM Breda's export containers to Rotterdam and Antwerp.

- `index.html` - the whole site in one file (live Data Studio dashboard, levelled data-lineage chart, results, scope check, project files)
- `downloads/` - Excel model, presentation, final report

Hosted with GitHub Pages: Settings > Pages > Deploy from a branch > `main` / root.

Team: Nelson Delarue, Emma Putod, Srikar Silveru, Peter Storey. Map data (c) OpenStreetMap contributors (ODbL).
